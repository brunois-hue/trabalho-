Vamos conhecer o mundo?

Navegadores antigos tinham uma frase gloriosa: "Navegar é preciso; viver não é preciso." Quero para mim o espírito desta frase, transformada a forma para a casar como eu sou: Viver não é necessário; o que é necessário é criar. Não conto gozar a minha vida; nem em gozá-la penso.
Só quero torná-la grande, ainda que para isso tenha de ser o meu corpo e a (minha alma)
a lenha desse fogo. Só quero torná-la de toda a humanidade;
ainda que para isso tenha de a perder como minha.
Fernado Pessoa
